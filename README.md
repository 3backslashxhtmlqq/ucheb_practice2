# Персональный книжный каталог с интеграцией Google Books API
Десктопное приложение на Java для ведения личных книжных коллекций с возможностью импорта метаданных через Google Books API. Поддерживаются роли Пользователь и Администратор, разграничение доступа, логирование действий и хранение впечатлений с цитатами.
Проект выполнен в рамках учебной практики и не предназначен для коммерческого использования.

### Логи программы: https://github.com/3backslashxhtmlqq/ucheb_practice2/blob/main/code/untitled1/data/logs.txt

## Основные возможности
### Для пользователя:
Регистрация и аутентификация (пароли хранятся в виде BCrypt-хэшей)
* Просмотр, добавление, редактирование и удаление книг в личном каталоге
* Поиск и фильтрация по названию, автору, жанру
* Импорт книги из Google Books API по названию или автору (заполнение полей автоматически)
* Добавление впечатлений (рецензий) и цитат с указанием страницы
* Настройка внешнего вида интерфейса (темы, шрифты)
### Для администратора
* Просмотр списка всех пользователей
* Создание, блокировка/разблокировка, удаление пользователей
* Назначение роли (USER / ADMIN)
* Просмотр и управление каталогами книг любого пользователя (добавление, редактирование, удаление)
* Просмотр общей статистики системы
### Прочее
* Логирование всех действий (SLF4J + Logback) с ротацией файлов
* Контроль дубликатов книг по ISBN или комбинации «название + автор»
* Транзакционная работа с БД – защита от потери данных
* Шифрование пароля подключения к БД (AES) в конфигурационном файле
## Требования к системе
* Операционная система: Windows 10/11, Linux, macOS (с поддержкой Java)
* Java: JRE / JDK 17 или выше
* СУБД: MySQL 8.0 (локально или в сети)
* ОЗУ: от 4 ГБ (рекомендуется)
* Дисковое пространство: от 500 МБ (с учётом БД и логов)
* Сеть: доступ к серверу MySQL (TCP/IP) и, для функций импорта, доступ в Интернет (HTTPS)
## Технологии и библиотеки
* Язык программирования - Java 17
* Графический интерфейc - Swing
* Доступ к БД - JDBC + HikariCP (пул соединений)
* База данных - MySQL 8.0
* Работа с JSON - Jackson
* HTTP-клиент	Встроенный - HttpURLConnection (или OkHttp)
* Хэширование паролей - jBCrypt (BCrypt)
* Шифрование конфигурации -AES (симметричное)
* Логирование - SLF4J + Logback
* Сборка - Maven / Gradle (JAR со всеми зависимостями)
## Установка и настройка
1. Установка MySQL и создание базы данных

Убедитесь, что сервер MySQL 8.0 запущен и доступен. Выполните следующие скрипты (например, через DBeaver или командную строку):
sql

``
CREATE DATABASE book_catalog CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'catalog_user'@'localhost' IDENTIFIED BY 'strong_password';
GRANT ALL PRIVILEGES ON book_catalog.* TO 'catalog_user'@'localhost';
FLUSH PRIVILEGES;
``

Для учебного проекта можно использовать пользователя root, но лучше создать отдельного.

2. Инициализация таблиц

Приложение автоматически создаст таблицы при первом запуске (Hibernate/DDL вручную не требуется, если вы реализовали инициализацию).
Однако рекомендуется выполнить схему из файла schema.sql (поставляется в комплекте).

3. Конфигурация подключения к БД

Создайте файл config.properties в рабочей директории приложения со следующим содержимым:

``
db.url=jdbc:mysql://localhost:3306/book_catalog?useSSL=false&serverTimezone=UTC
db.username=catalog_user
db.encrypted.password=<зашифрованный_пароль>
``

Важно: пароль к БД хранится в зашифрованном виде (AES).
Для генерации зашифрованного пароля используйте утилиту, поставляемую с проектом (PasswordEncryptor.java), или встроенную функцию при первом запуске.
Ключ шифрования задаётся в коде (для учебного проекта допустимо фиксированное значение, но в реальной системе используется внешний механизм).

4. Настройка логирования

Конфигурация Logback находится в logback.xml. По умолчанию логи пишутся в файл logs/app.log с ежедневной ротацией и дублируются в консоль.
При необходимости измените путь или уровень логирования.

5. Запуск приложения

Скачайте JAR-файл (или соберите из исходников):
``
java -jar build.jar
``

При первом запуске приложение проверит подключение к БД и создаст необходимые таблицы, если их нет.
Администратор создаётся автоматически при отсутствии пользователей:
Логин: admin
Пароль: admin (после первого входа настоятельно смените пароль).
## Использование
Регистрация и вход

1. При запуске отображается окно авторизации.
2. Нажмите «Регистрация», укажите логин и пароль (пароль дважды).
3. После успешной регистрации выполните вход с созданными учётными данными.
4. Для входа под администратором используйте логин admin и пароль по умолчанию.

## Основные действия пользователя
* Просмотр каталога - после входа открывается таблица со всеми книгами пользователя.
* Добавление книги - Кнопка «Добавить» → заполнить поля вручную или через «Импорт из API».
* Импорт из Google Books API - Ввести поисковый запрос (название, автор), выбрать книгу из списка → автозаполнение формы.
* Редактирование книги - Выбрать книгу → кнопка «Редактировать».
* Удаление книги - Выбрать книгу → кнопка «Удалить» (с подтверждением).
* Поиск и фильтрация - Ввести текст в поле поиска (по названию/автору) и/или выбрать жанр.
* Оставить впечатление - Открыть карточку книги → вкладка «Впечатления» → добавить текст.
* Добавить цитату	- В карточке книги → вкладка «Цитаты» → указать текст и страницу.
## Административные функции
* Пользователи: меню "Списки пользователи" - добавить, удалить, заблокировать, разблокировать, назначить роль
* Каталоги пользователей: меню "Каталоги пользователи" - добавлять, удалять, редактировать
* Статистика: меню "Логирование"
* Разграничение доступа

При попытке выполнить действие, не разрешённое для вашей роли, появится сообщение: «Недостаточно прав».
Для обычного пользователя скрыты пункты меню администратора и кнопки управления чужими каталогами.

## Примечания

* Приложение является учебным проектом, разработанным в рамках учебной практики.
* Google Books API используется для некоммерческих образовательных целей. При отсутствии интернета импорт недоступен, но локальный каталог работает.
* Пароли пользователей хранятся только в виде BCrypt-хэшей; восстановление пароля невозможно – только сброс администратором.
